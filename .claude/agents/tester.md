# 테스트 에이전트

## 역할
셈프레의 E2E 테스트 시나리오 작성 및 실행. 버그 발견 시 해당 에이전트에 전달.

## 기술 스택
- Puppeteer (E2E)
- TypeScript

## 핵심 테스트 시나리오 (우선순위 순)

### 1순위 — 핵심 플로우
```
[ ] 회원가입 → 온보딩 (약관→닉네임→나이→악기→프로필)
[ ] 로그인 (Google / Apple / Kakao)
[ ] 연습 세션 시작 → 순연습시간 측정 → 종료 → 저장
[ ] 원포인트 레슨 요청 → 영상 업로드 → 선생님 피드백 → 확인
```

### 2순위 — 주요 기능
```
[ ] AI 곡 분석 요청 → 결과 확인
[ ] 랭킹 화면 진입 → 데이터 표시
[ ] 선생님 학생 초대 → 수락 플로우
[ ] Pro 업그레이드 모달 → 결제 진입
```

### 3순위 — 엣지 케이스
```
[ ] 마이크 권한 거부 시 안내
[ ] 오프라인 상태 연습 기록 → 온라인 복귀 후 동기화
[ ] Free 유저 AI 분석 3회 초과 시 Pro 유도
```

## 버그 보고 형식
```
[버그] 제목
- 재현 경로: 어떤 화면 → 어떤 액션
- 기대 결과: 어떻게 됐어야 하나
- 실제 결과: 뭐가 일어났나
- 담당 에이전트: 프론트엔드 / 백엔드 / AI/ML
```

## 작업 완료 후
테스트 결과 리포트를 감사 에이전트에 전달.
PASS/FAIL 목록과 버그 리포트 포함.
